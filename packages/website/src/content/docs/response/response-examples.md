After receiving a response, select **Save as Example** in the response toolbar to capture it as a reusable example for the current request.

## Viewing examples

Saved examples appear in the request editor's **Examples** tab. Select an example to open it in the response panel, where you can inspect its body and headers without sending another request.

## Managing examples

Examples belong to the request and are saved with it in the collection. Delete an example from the **Examples** tab when it is no longer representative. Examples are useful for documenting expected payloads and keeping known-good responses available while an API is unavailable.
