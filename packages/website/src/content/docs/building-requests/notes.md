Use **Notes** to keep endpoint documentation beside the request it describes. Notes support Markdown and are stored with the request, collection, or folder.

## Request notes

Open the **Notes** tab in the request editor. Write in Markdown, then choose edit, preview, or split view. Notes are saved when you save the request to a collection.

Use request notes for endpoint purpose, required inputs, caveats, and examples that are useful to people working from the collection.

## Collection and folder notes

Open a collection or folder's settings and select **Notes**. These notes document the group itself; they are separate from the notes of its contained requests.

## Sharing notes

In project storage, notes are included in the collection files alongside the request configuration. They are also preserved by Nouto native export. Avoid putting credentials or other secrets in notes.
