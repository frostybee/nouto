Deleting a collection, folder, or saved request moves it to **Trash** instead of removing it immediately.

## Restore an item

Open the **Trash** tab in the sidebar and select **Restore** beside an item. Nouto returns the item to the collection and folder shown in its original-location label.

## Permanently delete items

Select **Delete permanently** for one item, or **Empty Trash** to remove every trashed item. Both actions require confirmation and cannot be undone.

Trash is for saved collection content. Request history has its own deletion and clearing controls; see [Request History](/tools/request-history).
